# واژه‌نامهٔ ترجمهٔ فارسی RikkaHub

راهنمای یکدستی ترجمهٔ فارسی (`values-fa`). در ترجمه‌های بعدی از همین معادل‌ها استفاده کنید.

## قواعد کلی
- از «ی» و «ک» فارسی استفاده شود (نه ي/ك عربی).
- نیم‌فاصله (ZWNJ) در «می‌»، «‌ها»، «‌ای»، «‌تر» و کلمات مرکب رعایت شود (مثل «می‌شود»، «پیام‌ها»).
- سه‌نقطه با نویسهٔ «…» نوشته شود.
- گیومهٔ فارسی «» برای نقل‌قول.
- نام برندها و اصطلاحات فنی لاتین بمانند: OpenAI، Gemini، Claude، MCP، Markdown، JSON، LaTeX، TTS، ASR، OCR، SSH، WebDAV، S3، Rootfs، Shell، Regex، WebSocket، User-Agent.
- برچسب دکمه‌ها کوتاه و مصدری/امری: «ذخیره»، «لغو»، «حذف»، «افزودن».
- placeholderها (`%s`، `%1$d`، `%%`)، escapeها (`\'`، `\"`، `\n`، `&amp;`) و Markdown بدون تغییر حفظ شوند.
